2. Testing, Refresh and Mock Cutover Inputs

Mock systems are built from a Production refresh by default. Non-production system upgrades, test activities, planning and preparation use the normal weekday single-shift calendar. Mock and Production cutovers are scheduled in weekend 24×7 mode.

3. Holiday Calendar and Working Model

Holidays are excluded from normal working activities. Weekend 24×7 cutover activities are not automatically stopped for holidays. Validate resource availability separately.

4. Generate, Research and Export

Microsoft Project XML can be imported directly into Microsoft Project and saved as a native `.mpp` file. Direct native `.mpp` generation requires a server-side MPP library such as Aspose.Tasks or MPXJ.
